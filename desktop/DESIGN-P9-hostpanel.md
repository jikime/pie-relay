# 호스트 패널 UI 정리·재배치 (progressive disclosure)

현재 HostPanel은 카드 4개에 모든 컨트롤이 평면 나열돼 복잡하다. 사용 빈도로 나눠
주 흐름은 상단에 선형으로, 고급/드문 것은 접이식으로 숨긴다. 기능 제거는 없다(로직 유지),
배치·노출만 바꾼다.

## 정보 구조 (위→아래)

### 1) 카드 "방"
- **호스트 토큰 없음**: 큰 [방 만들기] 버튼. (로컬 릴레이면 키 없이 즉시. 공개 릴레이/이름
  지정은 아래 고급.) 만들면 방·만료 표시.
- **호스트 토큰 있음**: "방: r-xxxx · 만료 …" 상태 + [토큰 지우기](=수동티켓/발급 상태 초기화, 선택).
- **방 타입** select (채팅/터미널) — 데몬 정지 시에만 변경. 터미널 힌트 유지.
- **데몬 상태 표시 + [데몬 시작/정지]**.
- **[이 방 참여]** — 데몬 실행 중 활성. 라벨을 "이 방 참여(모니터링·승인)"로 명확화.
  (호스트가 자기 방에 role=host로 들어가 승인 카드/드라이버 제어/화면을 봄 — 유지.)

### 2) 카드 "초대"
- 초대 등급 라디오(관전/조작) + 힌트.
- [초대 코드 발급] + 발급 코드 박스(코드·등급 배지·복사).

### 3) 접이식 "고급 설정" (기본 접힘, 토글로 펼침)
- 릴레이 주소(agent 엔드포인트).
- 수동 티켓(RELAY_TICKET) — 방 만들기가 자동 채우므로 평소 안 씀. 다른 소스(-mint) 토큰
  붙여넣기용.
- 발급 키(HOST_ENROLL_SECRET)·방 이름·내 이름 — 방 만들기 옵션(공개 릴레이/이름 지정 시).
- 권한 모드(채팅 방 정책) + bypass 경고.
- 작업 디렉토리(기본 cwd).
- [다른 기기용 토큰 복사] — 다른 기기에서 호스트로 붙여넣을 때만. 드묾.

### 4) 접이식 "사이드카 로그" (기본 접힘 또는 축소, [지우기])

## 구현 지침
- HostPanel.tsx 렌더 트리만 재구성. 상태·핸들러(onCreateRoom/onToggleDaemon/onOpenRoom/
  onCopyToken/onCreateInvite/enroll/ticket/permissionMode/defaultCwd/roomMode 등) 전부 유지.
- 접이식은 로컬 useState(고급 펼침 여부, 로그 펼침 여부) + 간단한 <details>/버튼. 펼침
  상태는 localStorage에 유지(선택).
- "방 만들기" 성공 후 발급 키/이름 입력은 고급에 있어도 동작(값 그대로 사용).
- 방 상태(토큰 유무·room·만료)는 기존 enrollInfo/ticket에서 유도. 토큰 있으면 방 만들기
  버튼 대신 상태 표시.
- styles.css: 접이식(.host-advanced, .host-collapse) 스타일. 기존 클래스 재사용 우선.
- 기능/문구 삭제 금지 — 위치만 이동. EXECUTOR_PATH는 이미 숨김(유지).

## 완료 기준
- npm run build / npx vitest run(기존 128 유지, 순수 로직 변화 없음) / cargo check 통과.
- README 호스트 절: 주 흐름(방 만들기→방 타입→데몬→이 방 참여→초대) + 고급 접이식 언급.
- GUI 실행 금지(레이아웃은 사용자 시각 확인).
