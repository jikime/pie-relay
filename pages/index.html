Pie Client

내 Mac 또는 Linux 컴퓨터를 Pie Relay 실행 장치로 안전하게 연결합니다. 설치 파일은 GitHub Release에서 내려받고 SHA-256 검증을 통과한 경우에만 설치됩니다.

빠른 설치

curl -fsSL https://jikime.github.io/pie-relay/install.sh | sh

Node.js 22 이상과 사용하려는 Claude Code 또는 Codex CLI 로그인이 필요합니다. 설치 스크립트는 관리자 권한 없이 사용자 홈 아래에 설치합니다.

장치 연결

pie-client connect \
  --server https://연결-코드를-발급한-서비스 \
  --code ABCD-EFGH

지원 환경

  • macOS: Apple Silicon, Intel
  • Linux: x86-64, ARM64
  • 버전 지정: install.sh --version v1.0.0
